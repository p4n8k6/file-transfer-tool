# File Transfer Tool

Python / Tkinterで開発したファイル転送ツールです。

既存のファイルコピーソフトの操作性を参考に独自実装し、Linux環境で使用できるよう開発しました。

## 機能
- ファイル・ディレクトリの複数選択
- ドラッグ＆ドロップ対応
- 更新日時を比較したコピー
- ファイル・ディレクトリの移動
- 処理ログの表示

## 使用技術
- Python
- Tkinter
- tkinterdnd2

## 起動方法
```bash
python file_transfer/main.py
```

#使用方法
①対象アイテムにコピー・移動したいファイルかフォルダをドラッグアンドドロップ。
　または、ファイルを選択・フォルダを選択ボタンから対象を選択する。
②コピー先の方にフォルダをドラッグアンドドロップ。
　または、参照ボタンでコピー先を選択する。
③モードを選択する
　1.差分（最新日付）:コピー先に同じ名前のファイルがある場合、ファイルの変更日時を参照し、対象アイテムが最新であればコピーする。そうでなければスキップする。
 2.移動（上書き）：コピー先に同じ名前のファイルがある場合も関係なくファイルを移動する。
